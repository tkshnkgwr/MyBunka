# セキュリティポリシー (SECURITY.md)

`bunka` プロジェクトのセキュリティ方針、サポート対象バージョン、および脆弱性報告手順について説明します。

---

## 1. サポート対象バージョン

セキュリティ更新が提供されるバージョンは以下の通りです。

| バージョン | サポート状況 |
| :--- | :--- |
| 0.4.x | :white_check_mark: サポート対象 (最新) |
| < 0.4.0 | :x: 非サポート |

---

## 2. 脆弱性の報告手順

本プロジェクトでセキュリティ上の問題や脆弱性を発見された場合は、公開Issueを作成せず、リポジトリのセキュリティタブ経由、または開発者への直接連絡にてご報告ください。

1. 報告内容（影響を受けるコンポーネント、再現手順、潜在的なリスク）を明記してください。
2. 受信後、迅速に影響範囲を調査し、パッチの作成および新バージョンのリリースを行います。
