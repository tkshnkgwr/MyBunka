## 3. 将来的な拡張提案 (Backlog)

- [ ] **標準入力（stdin / パイプライン）対応**
  - `echo "0.142857" | MyBunka` や `cat list.txt | MyBunka` のように、コマンドライン引数だけでなく標準入力からのストリーム受け付けに対応し、シェルスクリプトや他ツールとのパイプライン連携を可能にする機能。
- [ ] **出力フォーマットの拡充（JSON / CSV / 帯分数）**
  - `--json` オプションによる構造化データ出力（例: `{"input": 0.142857, "numerator": 1, "denominator": 7, "error": 0.00000014}`）。
  - `--mixed` / `-m` オプションによる帯分数（Mixed Fraction）形式の出力（例: `3.141592` に対する `3 1/7` のような整数部と真分数部の分離表示）。
- [ ] **連分数展開プロセスの可視化（Verbose / Stepモード）**
  - `--verbose` オプションにより、連分数の各係数列 `[a0; a1, a2, ...]` や、収束していく各ステップの近似分数・誤差の推移を表形式で詳細出力する機能。
- [ ] **簡易電卓機能 (Expression Parser)**
  - 単一の数値だけでなく、簡単な数式（例: `0.5 + 1/3` や `10% * 3`）を入力し、その算出結果を分数近似する機能。
- [ ] **連続変換モード (Interactive REPL)**
  - CLI環境において一度のコマンド実行で終了するだけでなく、対話的に数値を連続入力して分数変換を行えるREPLモードの導入。
- [ ] **クロスプラットフォーム自動リリース対応 (Linux / macOS)**
  - `.github/workflows/release.yml` を拡張し、Windows だけでなく Linux (x86_64, aarch64) および macOS (Apple Silicon / Intel) 向けの配布バイナリを自動生成・デプロイするマトリックスビルドの構築。
- [ ] **シェル自動補完スクリプト生成 (Shell Completions)**
  - `--completions bash|zsh|powershell|fish` オプションを指定することで、各シェル向けの引数自動補完スクリプトを出力する機能。
