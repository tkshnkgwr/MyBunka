# システム設計書 (ARCHITECTURE.md)

このドキュメントでは、`MyBunka` のシステムアーキテクチャ、ディレクトリ構造の意図、技術スタック、およびモジュール間のデータフローについて説明します。

---

## 1. システムの概要と目的

`MyBunka` (分化) は、浮動小数点数（例: `0.142857`）やパーセント表記（例: `10%`）の数値入力を、有理数としての最適な既約分数形式（例: `1/7`, `1/10`）に近似変換するアプリケーションおよびライブラリです。

### 開発の目的

- **高精度な有理数近似**: 小数点数から人間が直感的に理解しやすい分数表現への高速かつ正確な変換。
- **軽量な CLI インターフェース**: 自動処理やスクリプト連携に適した外部依存ゼロの極小 **CLI ツール**。
- **高効率と省リソース**: メモリ割り当て（ヒープ）を抑えた高速な近似アルゴリズムと、最適化されたフットプリントの実現。

### ディレクトリ設計の意図

- **コアロジックの純粋性 (`src/lib.rs`)**:
  - 近似アルゴリズム（連分数展開）や入力値のパース処理は、CLI の I/O 層から完全に独立しています。これにより、依存関係を極小化でき、テスト容易性も確保されます。
- **環境に依存しない構成管理 (`docs/`)**:
  - すべてのドキュメントファイルは `UPPER_SNAKE_CASE.md` 形式で統一し、`docs/en/` および `docs/ja/` 配下に多言語構成で集約することで、プロジェクトルートの視認性を高めています。また、ドキュメント内の相互参照リンクはすべて相対パスで記述されています。

## 4. データフローとモジュール間連携

`MyBunka` のデータ処理フローは、ピュアな処理を担当するライブラリコア（`src/lib.rs`）を中心に設計されています。

### 4.1 CLI 実行時のデータフロー

1. `main.rs` から `cli::run_cli()` が呼び出されます。
2. `cli.rs` が `std::env::args()` からコマンドライン引数をパースします。
3. 数値文字列を `lib::parse_decimal_or_percent()` に渡し、パーセント表記や通常の小数形式を解析して `f64` 実数を得ます。
4. 解析された数値、およびオプション引数（最大分母 `-d`, 許容誤差 `-t`）を `lib::approximate_fraction()` に渡します。
5. 得られた結果（分子、分母）を `stdout` に `分子/分母` 形式で出力して終了します。
