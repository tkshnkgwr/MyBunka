## 3. 将来的な拡張提案 (Backlog)

- [ ] **変換履歴機能 (History)**
  - 過去に近似変換した小数点数と結果分数の履歴を数件保持し、GUI上でリストから選択して再利用できる機能。
- [ ] **簡易電卓機能 (Expression Parser)**
  - 単一の数値だけでなく、簡単な数式（例: `0.5 + 1/3` や `10% * 3`）を入力し、その算出結果を分数近似する機能。
- [ ] **GUIの多言語対応 (Internationalization)**
  - UI上のテキスト（Decimal, Max Denom, Tolerance 等）をシステムロケールや設定によって日本語表記（小数値, 最大分母, 許容誤差 等）に切り替える機能。
- [ ] **クロスプラットフォーム対応の強化**
  - 現在、GUI版の二重起動防止（Named Mutex）は Windows 環境に依存しています。macOS や Linux などでビルド・実行する場合に、条件付きコンパイル等を用いて安全に起動（または代替の多重起動防止策を実行）できるようにする。
